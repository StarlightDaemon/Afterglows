# Visual Standard Campaign — operator workflow

The operator's 2026-09-08 feedback supersedes the initial campaign prompt's
frequent review stops and mandatory repeat review after every correction.

- Aim for roughly 20 revised concepts per operator checkpoint. Revise only
  concepts with identified issues; do not change passing work to meet a quota.
- Work and validate continuously in small internal groups. Those groups are
  implementation checkpoints, not requests for operator approval.
- Apply clear operator feedback, verify the correction, and continue. Request
  another focused review only for unresolved visual choices or material issues.
- Keep the questionnaire simple: Approve, Revise, Keep previous, quality rating,
  one Play/Pause control and optional comments. Advanced inspection stays collapsed.
- Preserve versions, provenance, evidence, deferred work and usage guardrails.
  Continue reporting concise progress and raise questions when judgment is needed.
- The operator explicitly authorized local checkpoint commits for accepted batches
  and automatic continuation on 2026-09-08. This authorization persists; do not
  ask again at each checkpoint. Commit accepted work before starting the next wave.
- Push, release and deployment remain separate operator decisions.

See `wave-01.json` for the accepted first-wave decisions and evidence.
