Retro FX

Library

A high-fidelity CRT simulation toolkit for scanlines, phosphor persistence, screen curvature, chromatic aberration, and reusable power-on effects. The components recreate the character and imperfect motion of physical displays without requiring vintage hardware. Combine the effects into a complete monitor treatment, from restrained terminal glass to degraded broadcast imagery, with direct control over every visual layer.

Matrix Code

Library

A standalone digital-rain toolkit with six switchable modes: classic CSS columns, Canvas rain, binary, film, draft, and trace, with independently themed colors. Each implementation is available as a focused demo and a reusable starting point for terminal interfaces. The modes range from lightweight decorative backgrounds to Canvas-driven fields for landing pages, dashboards, terminals, and standalone visual experiments.

Animation Concepts

Archive

1,000 motion experiments across 13 disciplines and 66 categories explore mathematics, physics, biology, machines, and unusual interfaces. Versioned refinements preserve earlier approaches while newer studies improve motion, physical behavior, and visual identity. The gallery is both archive and laboratory: compare iterations, inspect source, and follow geometry, culture, and everyday systems as they become recognizable animated objects.
